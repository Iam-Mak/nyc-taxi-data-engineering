# NYC Taxi Data Engineering

An exploration of large-scale data engineering using NYC Taxi trip records, with a focus on distributed processing, Spark execution and building efficient, reliable data pipelines.

The work covers practical data ingestion, transformation, performance analysis and optimisation using Azure Databricks.

## Data Source

[NYC Taxi & Limousine Commission – Trip Record Data](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page)
